# estudos-java-ps2-mackenzie

Repositório destinado à disciplina **Programação de Sistemas II** do curso de **Sistemas de Informação** na **Universidade Presbiteriana Mackenzie**.

> Estudando Java por aqui!



## 📚 Ementa da matéria

Abaixo estão todos os tópicos teóricos e práticos abordados durante a matéria:

1. **Revisão aos Conceitos de Orientação a Objetos**
    - 1.1. Tratamento de Exceções
    - 1.2. Polimorfismo
    - 1.3. Classes abstratas
    - 1.4. Interfaces
2. **Collections e Generics**
3. **Persistência em arquivos**
4. **Persistência em Banco de Dados Relacional**
    - 4.1. Bancos de dados relacionais (tabelas, campos, índices e queries básicas)
    - 4.2. Desenvolvimento de aplicações Java com acesso à base dados utilizando JDBC
    - 4.3. Mapeamento objeto-relacional (ORM)
    - 4.4. Data Access Object (DAO)
5. **Desenvolvimento de aplicações WEB**
    - 5.1. Aplicação WEB com páginas estáticas
    - 5.2. Protocolo HTTP
6. **Interfaces funcionais e streams em Java**
7. **Web Services e construção de APIs RESTful com Spring Boot**
    - 7.1. JSON/REST
    - 7.2. Implementação de Web Services REST e construção de APIs RESTful
    - 7.3. Spring Data JPA (Entidades simples, associações entre entidades, herança entre entidades)
8. **Single Page Application (SPA)**
    - 8.1. Desenvolvimento em JavaScript
    - 8.2. Consumo de Web Services utilizando Javascript
    - 8.3. Desenvolvimento de aplicações SPA (Single Page Application)

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem Principal:** Java
- **Framework:** Spring
- **Persistência:** JDBC, Spring Data JPA, PostgreSQL/Supabase
- **Web:** Spring Web, Protocolo HTTP, JSON, REST e APIs RESTful
- **Frontend:** JavaScript com React
- **Ferramentas:** Git, Maven/Gradle
